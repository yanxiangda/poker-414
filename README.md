## 📖 游戏规则（详细版）

### 基本规则

1. **牌数**：使用 **3 副牌**（共 162 张），包含 6 张王（3 大王 + 3 小王）
2. **人数**：**6 人** 参与游戏（可添加机器人凑齐人数）
3. **分队**：按座位交替分队
   - **A 队**：玩家 1、3、5（绿色）
   - **B 队**：玩家 2、4、6（红色）
4. **发牌**：每人 **27 张牌**
5. **出牌顺序**：顺时针出牌，玩家 1 先手
6. **获胜条件**：某队先出完牌 **且** 该队积分 ≥ 135 分

---

### 牌型与大小

#### 单张
```
大王 > 小王 > 3 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4
```

#### 对子
两张相同点数的牌（如：KK、AA）

#### 炸（炸弹）
**3 张或以上** 相同点数的牌（如：KKK、AAAA）
- 炸可以管单张、对子
- 炸可以管顺子、双龙
- 张数多的炸可以管张数少的炸

#### 顺子
**3 张或以上** 连续的单张（如：456、78910JQ）
- 不能包含大小王
- 顺子算 **3 路**

#### 双龙
**3 对或以上** 连续的对子（如：445566、991010JJQQ）
- 双龙算 **4 路**

#### 幺牌（414）
**1 个 A + N 个 4**（N ≥ 2）
- 例如：A+44、A+444、A+4444
- 幺牌可以管单张、对子、炸
- 路数计算：`4 + (4 的个数 - 2) × 2`
  - A+44 = 4 路
  - A+444 = 6 路
  - A+4444 = 8 路

#### 王组合
**2 张或以上** 的王（大小王混合）
- 路数计算：`小王 × 1.5 + 大王 × 2.5`
  - 2 小王 = 3 路
  - 1 大王 1 小王 = 4 路
  - 2 大王 = 5 路

---

### 管牌规则

| 上家出牌 | 你可以出 | 说明 |
|---------|---------|------|
| 单张 | 更大的单张 | 必须同类型且更大 |
| 单张 | 炸 | 炸可以管单张 |
| 单张 | 幺牌 | 幺牌可以管单张 |
| 对子 | 更大的对子 | 必须同类型且更大 |
| 对子 | 炸 | 炸可以管对子 |
| 对子 | 幺牌 | 幺牌可以管对子 |
| 炸 | 更大的炸 | 张数更多，或张数相同但点数更大 |
| 炸 | 幺牌 | 幺牌路数 ≥ 炸的路数 |
| 炸 | 王组合 | 王组合路数 > 炸的路数 |
| 顺子 | 更大的顺子 | 必须同类型且更大 |
| 顺子 | 炸（≥3 张） | 炸可以管顺子 |
| 双龙 | 更大的双龙 | 必须同类型且更大 |
| 双龙 | 炸（≥4 张） | 炸可以管双龙 |
| 王组合 | 炸（≥3 路） | 3 路以上的炸可以管王组合 |

**过牌**：管不上可以选择"过"，连续 5 人过后，最后一手出牌的玩家获得出牌权。

---

### 特殊规则：借光

当一名玩家出完所有手牌后：
1. 如果一圈没人要（其他玩家都过）
2. 出完牌玩家的 **同队下一个有手牌的玩家** 获得 **先手出牌权**
3. 桌面牌清空，可以任意出牌

**示例**：
- 玩家 0（A 队）出完牌
- 一圈没人要
- 玩家 2（A 队）还有手牌 → 玩家 2 **借光**，获得先手
- 如果玩家 2 也出完了，找玩家 4（A 队）

---

### 计分规则

#### 分数牌
- **K**：10 分
- **10**：10 分  
- **5**：5 分
- 其他牌：0 分

#### 得分流程
1. 每轮出牌后，桌上所有分数牌归 **最后一手出牌的玩家所在队伍**
2. 当一圈没人要时，触发计分：
   - 计算桌上所有分数牌的总分
   - 分数加给 **lastPlayer**（最后一手出牌的玩家）所在队伍
   - 清空桌面，lastPlayer 获得先手出牌权

#### 获胜判定
- **先出完牌的队伍**：需要 ≥ 135 分获胜
- **后出完牌的队伍**：需要 ≥ 210 分获胜

#### 特殊牌型（路数）
- **小雪**：输方积分 ≤ 10 分 → 赢方分数 × 5
- **大雪**：输方积分 ≤ 40 分 → 赢方分数 × 25
- **普通**：输方积分 > 40 分 → 无倍率

## 🎮 快速开始

### 环境要求

- Node.js >= 16.x
- npm >= 8.x

### 1. 克隆项目

```bash
git clone git@github.com:yanxiangda/poker-414.git
cd poker-414
```

### 2. 安装服务器依赖

```bash
cd server
npm install
```

### 3. 安装前端依赖

```bash
cd ../frontend
npm install
```

### 4. 启动服务器

```bash
cd ../server
npm start
```

服务器运行在：`http://localhost:3001`

### 5. 构建前端

```bash
cd ../frontend
npm run build
```

### 6. 开始游戏

打开浏览器访问 `http://localhost:3001`，输入昵称后即可创建或加入房间！

## ❓ 常见问题

### Q: 无法连接服务器？
A: 检查服务器是否启动，确认端口 3001 未被占用。局域网访问需使用服务器 IP。

### Q: 房间号无法加入？
A: 确认房间号正确（6 位），且房间未满（最多 6 人）。

### Q: 出牌无效，提示"这牌管不上"？
A: 检查是否符合管牌规则：
- 必须出相同牌型且更大的牌
- 或使用特殊规则（炸、幺牌、王组合）
- 或选择"过"

### Q: 为什么我出完牌后，同队玩家获得出牌权？
A: 这是东北抛幺的 **"借光"** 规则，出完牌后同队下一个有手牌的玩家获得先手。

### Q: 如何分享给朋友？
A: 创建房间后，将 6 位房间号分享给朋友，他们输入房间号即可加入。

### Q: 一个人能玩吗？
A: 可以！创建房间后点击"添加机器人"，单人也能体验游戏。
